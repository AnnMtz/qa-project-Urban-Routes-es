# AUTOMATION TESTING OF URBAN ROUTES

# Descripción
Se realizaron pruebas automaticas para validar el flujo de la solicitud de un taxi en la aplicación web Urban Routes
A través de estas pruebas se verificó el comportamiento de la interfaz completa desde la selección de la ruta hasta la asignación del conductor,
se validó el número de teléfono y tarjeta para el pago del viaje.

Dichas pruebas se ejecutaron con Selenium, Pytest y Page Object Model (POM)

# Tecnologías usadas
1. Python
2. Selenium 4.41.0
3. WebDriver.Chrome
4. Selenium WebDriver
5. Page Object Model (POM)

# Funcionalidades
Se probaron las siguientes funcionalidades de la aplicación

1. Configurar dirección de origen y destino
2. Seleccionar tarifa Comfort
3. Registrar número de teléfono
4. Confirmar código SMS
5. Agregar tarjeta de crédito
6. Escribir mensaje al conductor
7. Solicitar manta y pañuelos
8. Agregar 2 helados
9. Solicitar taxi
10. Esperar asignación de conductor
